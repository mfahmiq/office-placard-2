# Office Placard — Fire Extinguisher

A one-line museum placard for an ordinary office object, written as if it were an ancient artifact dug from a lost civilisation. Built for the make.fun bounty "Office Artifacts: The One-Line Placard Contest".

## The entry

> Fire extinguisher, c. 1994. Red steel, untouched. A guardian god, inspected yearly, invoked never. Donated by Health & Safety.

## How it works

`main.py` writes the placard line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`). See `CANDIDATES.md` for the 16-candidate tournament that picked this line.
